# ECSE 552 - Assignment 2

Coursework for deep-learning assignments, implemented in Python and Jupyter notebooks.

## Contents

- `Assignment_2_part_1.ipynb` - forward/backward passes and backpropagation exercises.
- `Assignment_2_part_2.ipynb` - PyTorch deep-learning experiments.
- `ECSE552_W25_Assignment2_part3_Group_5.ipynb` - data cleaning and Part 3 work.
- `ECSE552/` - NumPy implementations of affine, convolutional, and RNN layers, plus gradient-checking utilities.
- `dictlogger.py` - lightweight PyTorch Lightning metrics logger.
- `sample_data/` - datasets used by the notebooks.
- `report/` - submitted report PDF.

## Run

Open a notebook in Jupyter or VS Code and run the cells from top to bottom.

```bash
pip install numpy matplotlib pandas pillow torch torchvision pytorch-lightning tqdm umap-learn scikit-learn
jupyter notebook
```
